# GymBro — дневник тренировок (Telegram Mini App)

Возможности:

- **Каталог упражнений.** 876 упражнений с фото (анимация из двух кадров), фильтрами по мышцам, оборудованию, уровню и типу. Для 169 популярных — русское название и техника. Кнопка видеоурока открывает поиск на YouTube. Можно добавлять свои упражнения.
- **Тренировка.** Для каждого подхода записываются вес и повторения, подставляются результаты прошлой тренировки. Есть разминочные подходы, RPE, заметки и отметка 🏆 PR при личном рекорде.
- **Таймер отдыха.** Запускается сам после подхода, кнопки ±15 с, в конце звук и вибрация. Время отдыха настраивается для каждого упражнения.
- **Готовые программы.** Full Body для новичков, Full Body A/B/C, Сила 5×5, Верх/Низ, Push/Pull/Legs, Сплит 5 дней, Дома с гантелями, Ноги и ягодицы. Можно создавать свои.
- **Статистика.** Тоннаж по неделям, подходы по группам мышц, календарь, серия недель подряд. Для каждого упражнения — график прогресса (1ПМ, максимальный вес, объём, повторы) и рекорды по числу повторений.
- **Данные.** Хранятся в IndexedDB и синхронизируются с Telegram CloudStorage. Есть экспорт и импорт в JSON.

## Локальный запуск

```bash
npm install
npm run dev
```

Приложение откроется на http://localhost:5173. Вне Telegram оно тоже работает, но без облачной синхронизации.

## Деплой на GitHub Pages

1. Создайте репозиторий на GitHub и отправьте в него код (ветка `main`).
2. В репозитории откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` соберёт и опубликует сайт по адресу `https://<user>.github.io/<repo>/`.

## Подключение к Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather): `/newbot`.
2. Привяжите Mini App: `/newapp` → выберите бота → укажите URL с GitHub Pages. В результате появится ссылка вида `t.me/<bot>/<app>`.
3. Можно также добавить кнопку меню: `/mybots` → бот → **Bot Settings → Menu Button** → URL.

## Обновление базы упражнений

```bash
git clone --depth 1 https://github.com/yuhonas/free-exercise-db /tmp/fedb
scripts/compress-images.sh /tmp/fedb/exercises public/img
npm run build:data -- /tmp/fedb
```

Русские переводы лежат в `scripts/ru-exercises.mjs`.
